# New Property Project Template

## Folder Structure
/photos       — raw uploads, organized by room/category
/copy         — listing narrative, bio, taglines, section copy
/docs         — floor plans, disclosures, blueprints, PDFs
/social       — Instagram captions, reels scripts, post graphics
/mls          — MLS-ready photo exports, descriptions, data sheet
/landing      — landing page JSX, design notes, Cloudinary URLs

## Checklist — New Listing Kickoff
- [ ] Create Property record in Photo Hub
- [ ] Upload all photos + categorize by room
- [ ] Run batch enhance (Cloudinary)
- [ ] Write listing narrative (copy/)
- [ ] Export MLS photos + description (mls/)
- [ ] Build landing page (landing/)
- [ ] Set up inquiry form + WhatsApp alert
- [ ] DNS / domain setup
- [ ] Go live

## Key Info to Collect at Intake
- Address, city, state
- Price
- Beds / baths / sq ft / lot size
- Year built
- Notable features (history, systems, land, views)
- Seller's emotional story — why are they selling, who is the ideal buyer?
- Matterport link (if available)
- Video links (Vimeo, YouTube)
- Domain (if custom)

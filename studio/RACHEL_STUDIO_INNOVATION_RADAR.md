# Rachel Studio Innovation Radar

Date: 2026-05-03

Purpose: keep Rachel Studio cutting edge without turning Rachel into the person who has to track every AI tool, changelog, beta, model release, and hype cycle.

## The Law

Rachel Studio should actively look for better tools.

But it should not chase novelty.

Every upgrade must answer:

1. Does this help property truth become better public work?
2. Does it improve visuals, media, SEO, research, backend, publishing, or review?
3. Can it be tested safely in preview?
4. Does it preserve Rachel approval?
5. Does it become reusable for future listings?

If not, it goes on the shelf.

## Scoring Rubric

Every found update gets scored:

| Score | Meaning | Action |
| --- | --- | --- |
| 5 | Directly improves current Garran Hill / Flow Farm work | test in preview now |
| 4 | Strong platform upgrade for next build phase | put in active backlog |
| 3 | Useful but not urgent | shelf for later |
| 2 | Interesting but risky or unclear | watch only |
| 1 | Hype / distraction | ignore |

## Output Format

The radar should return:

1. What changed
2. Why it matters to Rachel Studio
3. Which lane it belongs to
4. Score from 1-5
5. Risk warning
6. Safe test plan
7. Keep / test / shelf / ignore

## Tool Lanes

Every upgrade must land in a lane:

- writing / editorial
- source research
- SEO / backlinks
- image enhancement
- video / social
- backend CMS
- preview / publish
- review board
- MCP / connectors
- analytics
- compliance / brokerage safety

## Safe Upgrade Path

No upgrade goes straight to production.

1. watch
2. summarize
3. score
4. map to Rachel Studio lane
5. test in preview
6. compare before/after
7. Rachel/Rocky approve
8. versioned platform upgrade

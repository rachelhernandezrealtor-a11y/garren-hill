# Rachel Studio Platform Modules

This folder holds private platform planning and operating documents for Rachel Studio.

Rachel Studio is the production platform behind the luxury property sites. The public property site is an output. The platform coordinates source truth, media truth, SEO, AI tools, preview review, and Rachel-approved publishing.

## Current Modules

- `RACHEL_STUDIO_AI_TOOL_ORCHESTRATION.md` explains which tool does which job.
- `RACHEL_STUDIO_INNOVATION_RADAR.md` defines how Rachel Studio watches current AI, SEO, backend, media, video, and MCP updates without chasing hype.
- `rachel-studio-system/innovation-radar.json` is the machine-readable radar configuration for future backend or MCP automation.

## Publishing Law

These documents do not change production by themselves.

Any public site change still requires preview review and explicit Rachel approval before production.
